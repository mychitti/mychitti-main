Laundry Module — Development Plan

MyChitti Platform  ·  April 2026

1. Two Operating Modes

Mode 1 — Walk-in Laundry

Individual customer drops clothes at the laundry, picks up after processing.

Flow: Drop-off → Tag items → Token receipt → Processing → Notify customer → Pickup → Payment + Invoice

Mode 2 — Hotel / B2B Challan

Hotel sends bulk linen in batches. Each batch is tracked via a challan with outward and inward dates.

Flow: Hotel sends batch → Outward challan → Processing → Return + inward entry → Balance tracked → Monthly invoice

2. Existing Modules Reused

Module Status How
StoreCustomer Full reuse Walk-in customers use user_type=customer. Hotels use user_type=vendor. No new table needed.
ManualInvoice Full reuse Payment invoices for both modes. Use type='laundry_walkin' or type='laundry_hotel' with module_id pointing to order/challan.
ReceivableReceipt Full reuse Drop-off token receipt for walk-in. Same pattern as task/lead receipts. Link via laundry_order_id.
InventoryGatepass Not reused Laundry challan needs balance carry-forward and per-item damage tracking. New laundry_challans table created instead.
Billing PDF (mPDF) Full reuse New blade template for challan print and invoice print, using existing mPDF helper.

4. Pages — Vendor Panel

Setup

  • Laundry Items — CRUD for item master (name, category, price, unit, active toggle)
  • Hotel Clients — Reuse existing Customer module filtered by user_type=vendor. No new page needed.

Walk-in Orders

  • New Order — Customer lookup (existing JS), add items from master, custom items allowed, auto-total, set expected ready date
  • Order List — Filter by status / date / customer. Status badges. Quick actions.
  • Order Detail — View items, update status (Received → Processing → Ready → Delivered), collect payment, generate invoice
  • Token Receipt Print — Reuse ReceivableReceipt template. Shows order no, customer, items, amount due, expected ready date
  • Invoice Print — Reuse ManualInvoice / existing billing PDF with type=laundry_walkin

Hotel / Challan

  • New Challan — Select hotel (store_customer user_type=vendor), add items with sent qty. Auto-fetches previous balance from last challan per item.
  • Challan List — Filter by hotel / status / date. Status: Pending / Partial / Returned.
  • Receive Challan — Fill received qty + damaged qty per item, set inward date. Balance auto-computed. Option to generate invoice.
  • Challan PDF Print — mPDF template matching hotel challan format (header, item table with prev balance / sent / total / received / damaged / balance / remarks, signatures)
  • Monthly Register — Grid view: rows = items, columns = days 1–31, cells show daily movement. Export to PDF.

Reports

  • Pending Balance — Items still out at hotels, grouped by hotel with challan-wise breakdown
  • Revenue — Walk-in + hotel invoice totals by date range
  • Item Volume — Most processed items, category-wise breakdown

5. Pages — Admin Panel

  • All Orders — Cross-vendor view of all laundry orders with store filter
  • All Challans — Cross-vendor challan list with pending balance highlights

7. Build Phases

  • Migration SQL (5 tables — ALTER TABLE queries)

  • Laundry Items CRUD (vendor settings page)
  • Sidebar menu entry

  • Pending balance report (items out at hotels)
  • Revenue report by date range
  • Item volume report
  • Admin panel — all orders + challans view
  • Export to PDF / Excel
